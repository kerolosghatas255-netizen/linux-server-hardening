Project Environments
PHASE 01

Remote ESXi Lab

Initial hardening and validation were performed on an Ubuntu VM hosted on a separate VMware ESXi hypervisor and administered remotely from a Windows workstation.

PHASE 02

VMware Workstation Continuation

The validated configuration was backed up, integrity-checked with SHA-256, restored into a local VMware Workstation environment, and revalidated before additional monitoring work was added.

Custom Administration Tools

security-status

Custom Bash tool that validates the effective SSH configuration, UFW state, Fail2ban jail, Nginx, automatic security updates, backup scheduling, and exposed TCP ports.

sudo security-status

server-health

Operational health tool with thresholds for CPU load, memory usage, disk usage, service availability, backup freshness, and an overall HEALTHY / WARNING / CRITICAL result.

sudo server-health
